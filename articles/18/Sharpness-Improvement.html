Images generated using Variational Autoencoders are generally not sharp as they try to learn an explicit distribution of the input with a multi-dimensional Gaussian distribution. We propose a sharpness loss term motivated by A New Method for Full Reference Image Blur Measure , to improve sharpness as a part of loss function and present the results on MNIST dataset.
